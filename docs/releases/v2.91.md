# ReKernelFlasher v2.91（20910）

发布日期：2026-11-15

本版本是 v2.9 的补丁版，修两类问题：**云仓库特性显示**与**社区源下载前确认**，并把新增界面的文案全部纳入多语言。

## 一、官方源特性显示名

官方源文件名里的三个缩写按实际含义展开显示，其余 token 保持原样大写：

| 文件名 token | 卡片显示 |
|---|---|
| `IN` | **BetterNet** |
| `DS` | **DroidSpace** |
| `LZ4` | **Lz4-Zarm** |
| `SUSFS` / `NOSUSFS` / `KPN` / `KPM` / `ADIOS` / `FIX` / `HMBRID` / `SSG` / `BBG` | 原样 |

- 特性 chip 的排序仍按原始 token（`SUSFS`、`KPM`、`HMBRID`、`FIX` 等在前的规则不变），`DS / IN / BBG` 依旧压到最后
- 搜索索引同时收录缩写与展示名，搜 `IN` 或 `BetterNet` 都能命中

## 二、社区源下载前确认

点社区卡片的「下载」不再立刻下载，而是弹出完整信息表：

- 适用机型 / 内核版本、管理器与版本、内核版本、特性、体积、上传时间、补充说明、上传者（可跳转 GitHub）、SHA-256
- **必须滑到底部**「下载」按钮才可点（内容不满一屏时直接视为已读）
- 确认后弹窗关闭，下载进度条照常显示在卡片上；下载完成的「是否刷写」确认流程不变
- 底部 `ⓘ` 按钮仍是纯信息查看（不带下载按钮）

## 三、多语言完善

- 补齐 **it / ja / pl / pt-BR / ru** 各自缺失的 25–28 个键（此前这些键在运行时回退成中文）
- 云仓库、更新弹窗、首页设备卡、设置页新增文案全部改为资源引用，不再硬编码中文
- 10 个语言包键数统一为 **161**，键集合、占位符（`%1$s` / `%1$d`）一致性校验通过
- 繁体修正：`language_zh` 由「简体中文」改为「簡體中文」；`hashes` 改为「雜湊值」

## 四、版本

- `versionCode` **20910** / `versionName` **2.91**
- 签名证书不变：`CN=Bacillusf`，SHA-256 `30a16460…ED957D`

## 已知遗留

- 槽位、备份、历史、百宝箱等早期页面的部分文案仍为硬编码中文，尚未纳入资源，将在后续版本分批处理。
