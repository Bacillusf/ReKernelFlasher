# ReKernelFlasher v2.7 (20700)

发布日期：2026-08-04

## 重点更新

- 迁移 KernelSU 3.2.5 Manager 的 MIUIx 视觉体验，主界面更接近 KSU 的布局、标题栏和底部液态玻璃导航。
- 底部导航栏改为 KSU 风格浮动液态玻璃实现，保留 blur、vibrancy、lens、高光、内阴影和选中 pill 动效。
- 主页面切换改用 KSU 同款 Pager 状态逻辑，左右滑动和底部栏点击同步，不再依赖手写阈值手势。
- 启动流程重做为统一启动检测页，首次启动和后续启动都使用同一套检测 UI，不再进入旧向导页面。
- 首次启动加入后端模块安装选择：先安装 RKF 后端模块，再按需选择 MagicMountRS 重定向方案或 Meta-OverlayFS 挂载方案。
- 百宝箱新增/整理解包入口，解包和解包记录分为二级页面，流程更清晰。
- 更新内置 arm64 magiskboot，修复部分设备 boot/init_boot/vendor_boot 解析兼容问题。

## 启动检测

启动检测现在覆盖以下项目：

- Root 授权状态
- Root 管理器类型：KernelSU、APatch、Magisk
- 内置 RKF 后端模块包
- 内置 META 模块包：MagicMountRS、Meta-OverlayFS
- 本地工作目录可写性
- RootService / AIDL 后端服务连接
- 后端工具准备
- 分区工具准备
- 刷写工具准备
- BusyBox 准备
- 脚本和 Payload-Dumper 解包工具准备

## 刷写与检测修复

- 修复 boot 镜像检测 fallback：按 boot.img、init_boot.img、vendor_boot.img 顺序尝试解析。
- 修复 magiskboot 工作目录依赖，所有 cleanup、unpack、cpio、sha1 都强制在应用 filesDir 下执行。
- 支持 ramdisk.cpio 和 vendor_ramdisk.cpio 检测，避免部分设备误报 boot.img 或 magiskboot unpack 失败。
- 工具释放逻辑改为按文件是否存在/大小是否一致复用，减少启动阶段重复复制。
- 批量 chmod 后端工具，减少启动阶段 shell 调用次数。

## UI 与交互

- 主 4 个页面支持左右滑动切换：首页、刷写、备份、设置。
- 底部导航栏避让改为滚动内容尾部 Spacer，不再给整页加固定底部 padding。
- 顶部标题栏避免采样底部玻璃内容，减少灰蒙和透层问题。
- 去除旧启动页面淡入淡出导致的残影，进入主页改为启动器式延迟后直接切换。
- 清理多余阴影、覆盖层和旧向导残留代码。

## 工具与模块

- 内置 RKF 后端模块，提供守护进程、AVB2.0 工具和隐藏 AVB 状态能力。
- 支持可选安装 MagicMountRS，用于 Magic Mount 重定向方案。
- 支持可选安装 Meta-OverlayFS，用于 OverlayFS 挂载方案。
- 保留 AK3 ZIP、分区镜像、KernelSU LKM、A/B 槽位、自动备份、Payload-Dumper 解包等核心能力。
