# ReKernelFlasher v2.8 (20800)

发布日期：2026-08-17

## 重点更新

- 修复 Android 13 以下因液态玻璃组件（miuix-blur 依赖 RuntimeShader / RenderEffect）导致的启动闪退：新增能力检测，Android 13+ 继续使用液态玻璃，Android 10–12 自动回退为普通组件。
- 重构自动备份权限逻辑：删除自动备份设置页原有的两条存储权限授权按钮与提示，改为在启动检查期间统一请求「所有文件访问」与「通知」权限；非阻塞，拒绝授权也能进入应用。
- 新增内核压缩包回滚能力：操作记录新增「刷入内核压缩包」条目类型，开启自动备份后刷入 AnyKernel3 前自动备份 boot 与 dtbo 两个分区；操作记录与自动备份记录右下角均支持一键回滚。
- 云 G(O)KI 仓库增强：包信息新增「管理器:版本号」红色圆角高亮，同管理器最新版本在文件名上方显示五角星与 `Latest {管理器} Anykernel3`，并让各管理器的最新包置顶排序。
- 百宝箱新增「开启无线调试端口」工具，支持在指定端口开启 adbd 服务（adb over TCP），带端口校验、通知权限检查与常驻通知。
- 清理旧功能与冗余资产，并补充中英文使用文档。

## 兼容性修复

- 液态玻璃（miuix-blur）库声明 `minSdkVersion=33`，在 Android 13 以下调用会闪退；现已加入 `LiquidGlassSupport.isSupported` 检测，并按能力在 `FloatingBottomBar`、`GlassNavigationBar`、`MainActivity` 中自动回退为普通 surface 与矩形导航。
- `minSdk` 保持为 Android 10（API 29）。

## 自动备份与权限

- 移除设置页「已授权 / 未授权」状态行与「前往系统设置开启所有文件访问权限」按钮。
- 启动时自动检查并请求：所有文件访问（Android 11+ 跳系统设置）、通知权限（Android 13+ 弹系统对话框）。
- 自动备份设置页新增使用说明与功能简介，以及「未授权必要权限」提示（点击跳系统设置）。

## 刷写与回滚

- 操作记录新增条目类型「刷入内核压缩包」；刷入 AnyKernel3 成功后记录该类型并关联自动备份时间戳。
- 开启自动备份后，刷入 AnyKernel3 前自动 `dd` 备份 `boot`、`dtbo` 到 `/sdcard/ReKernelFlasher/Autobackup/{时间戳}/`。
- 操作记录页与自动备份记录页右下角均显示「回滚」按钮（带二次确认），点击后把备份镜像刷回原分区。
- 日志展示统一为 `源 -> 目标` 格式：操作日志 `刷入 {zip} -> {boot 块设备}`，自动备份日志 `{块设备} -> {备份镜像}`。

## 百宝箱

- 移除「自动禁用 AVB2.0」与「隐藏 AVB 状态」开关。
- 新增「开启无线调试端口」：输入 `1024–65535` 端口，合法时纸飞机按钮变亮，检查通知权限后执行 `setprop service.adb.tcp.port {端口} && stop adbd && start adbd`；开启后显示常驻通知（含停止按钮），停止时执行 `setprop service.adb.tcp.port 0 && stop adbd && start adbd`。
- 修复 RKP、开启高通 Diag 端口、解包、字库备份等工具保留并补充说明。

## 移除内容

- 首次启动 / 版本更新向导。
- 模块安装逻辑（RKF 后端模块 + MagicMountRS / Meta-OverlayFS 元模块）。
- 设置中「重新启动向导」按钮。
- 模块压缩包资产（RKF.zip、magic_mount_rs.zip、overlayfs.zip），APK 体积约从 25.1 MB 降至 22.6 MB。
