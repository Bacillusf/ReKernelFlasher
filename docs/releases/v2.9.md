# ReKernelFlasher v2.9（20900）

发布日期：2026-11-15

覆盖范围：`v2.8 (20800)` 之后到本版本的全部改动。

## 一、新增功能

### 1. 百宝箱 · RKPConfig（远程密钥分配）

入口：**设置 → 百宝箱 → RKPConfig**，从团队测试项目 True RKP 移植进主程序。

- 读取 / 应用 RKP 配置（启用 RKP、服务器地址含 Google 与 GrapheneOS 快捷项、仅 StrongBox、仅 TEE、连接超时）
- 续期签发、查看状态、生成 CSR、校验证书、进入工程模式、清空数据
- 支持自定义 `su` 路径（长按「应用配置」）、日志落盘 `filesDir/rkp.log`
- 实现方式：内嵌 AOSP `com.android.rkpdapp`，用 `libnsexec.so` 进入 init 的 mount namespace 后以 `app_process` 拉起，进程名伪装为 `com.android.rkpdapp`；补了 `IPackageManager` 代理（国内无 GMS 机型 `cn.google.services` 恒 false）与自建 `PathClassLoader`（APEX 安装包会返回空 DexPathList）

### 2. 百宝箱 · 开启无线调试端口

- 输入 `1024–65535` 端口，端口合法时发送按钮才点亮，非法时表单下方红字提示
- 开启前检查通知权限，未授权拉起系统授权框；成功后显示常驻通知（内含「停止」）
- 执行链路：`setprop service.adb.tcp.port {端口} && stop adbd && start adbd`，停止时把端口置 0 再重启 adbd
- 页面每秒轮询 `service.adb.tcp.port`，**已开启的端口会自动识别并跳过重复开启**，界面直接呈现「已开启」状态（1 秒一次，避免 0–1023 被误判成已开启）

### 3. 云 G(O)KI 仓库 · 官方源 / 社区源双源

云仓库不再直连 GitHub，改为读取官网接口：

| 源 | 接口 | 数据 |
|---|---|---|
| 官方源 | `/resources/api/official` | 121 条纯链接清单 |
| 社区源 | `/resources/api/community` | 用户上传的 JSON（作者、特性、体积、SHA-256、补充说明） |

- 顶部新增「官方源 / 社区源」下拉；官方源筛选为 `类型 / 版本 / 管理器`，社区源只保留 `管理器`
- 官方源分类按**路径**判定：`AnyKernel3_Official/MIXKI/**` → 内核通刷，`AnyKernel3_Official/OORB/**` → OnePlus 机型（原 tag 判定 `OORB-ONEP` / `OPPO-OPlus-Realme` 已废弃），平台（GKI / MTK）不再区分
- 机型代码自动还原成可读名（`ONEP13T` → OnePlus 13T、`ONEPACE5PRO` → Ace 5 Pro、`ONEPNORDCE4LITE5G` → Nord CE 4 Lite 5G 等 46 种）
- 社区卡片显示体积 / 上传者 / 上传时间，`ⓘ` 打开完整信息表（含一键复制 SHA-256、跳转作者主页与仓库页）；首次进入社区源弹「未经官方验证，认准作者」提示
- 搜索改为全字段索引：文件名、机型、内核版本/系列、管理器及版本、特性、补充说明、作者

### 4. 更新弹窗 · 先看更新说明再更新

- 点击「下载更新」/「下载」后先弹出该版本 GitHub Release 的更新说明，Markdown 渲染（标题、有序/无序/嵌套列表、引用、代码块、分隔线、粗体、行内代码、链接、斜体），可滚动
- **滑到底部才能点「更新」**；内容不满一屏时直接视为已读。首页横幅与设置页「检查更新」共用同一个弹窗
- 确认后才进入原有的下载 → 校验 → 拉起系统安装器流程

### 5. 中英文使用文档

新增 `docs/USAGE.md` 与 `docs/USAGE_EN.md`，覆盖主页信息、槽位、刷写、备份恢复、百宝箱各工具、设置项，配 17 张界面截图。

## 二、优化

- **云仓库卡片信息**：管理器与版本合并为红色高亮 `KSU-Next:33548`；同管理器最新版本加五角星 `Latest {管理器} Anykernel3`，并置顶排序（内核通刷按「内核系列 + 管理器」各取最高内核版本）
- **筛选栏收成单排**：四个下拉一行排布，未筛选时显示 `类型 / 版本 / 管理器` 字段名，选中后直接显示取值
- **界面缩放（DPI）持久化**：原先仅当次会话生效，现在写入 `SharedPreferences`，重启后保持
- **无线调试端口状态**：从「点了才知道」变为页面实时反映真实状态

## 三、修复

- **多语言**：修正 zh-HK / zh-TW / en 的多处翻译；修正简中映射错误（`zh` → `zh-CN`），此前非繁中/英文环境会回落到无 `-CN` 的资源
- **刷写日志可读性**：日志文本颜色跟随主题（深色模式下不再发灰）
- **首页重启图标**着色，按钮不再与背景融为一体
- **RKP 文档**：补齐构建注意事项与签名说明

## 四、移除

- **刷写 → 刷入 KernelSU LKM 驱动**：入口、`SlotViewModel.flashKsuDriver()` 实现、二次确认分支、`ksuinit` 资产与 10 个语言包的对应文案全部删除（上游继承功能，按 v2.8 的计划在本版本移除），APK 体积约减 0.24 MB
