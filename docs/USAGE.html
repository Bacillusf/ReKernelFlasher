1. 信息读取 & 展示（主页）

应用启动后会自动读取设备相关信息并展示在主页，如下图所示：

主页会自动读取以下信息：

  • 设备 ROOT 管理器
  • 安卓版本
  • 设备代号
  • 系统构建版本
  • 当前槽位
  • BootHAL
  • SUSFS Version
  • 内核版本

2. 槽位 & 内核版本检查

切换到「刷写」板块，如果你的手机支持 AB 分区，这里会显示两个槽位的信息。

信息板块会分别显示：

  • 活跃状态
  • Vendor_DLKM
  • boot.img / init_boot.img 相关信息
提示：点击「检查内核版本」按钮会重新刷新并解析当前内核版本信息。

3. 刷入功能介绍

在「刷写」页面点击「刷入」按钮进入刷写页面：

3.1 刷入 AK3

  1. 本地刷写：点击「刷写 AK3」按钮，选择你的 AnyKernel3 压缩包，此时会弹出二次确认弹窗，点击确认即可开始刷写。
  2. 使用云上 G(O)KI 刷写：回到刷写页面，点击右上角云朵图标进入云 G(O)KI 仓库，选择你对应的包，点击右下角「下载」，下载完成后会询问是否自动刷写，点击确认即可完成刷写。
  3. 特别提示：您可以完全信任云 G(O)KI 内下载的内容。但需要特别注意的是，我们强烈建议您在设置中打开「自动备份」开关，以免开机后遇到屏幕闪烁、显示异常等异常情况时，可以快速回滚您的快照备份。
  4. 重要提示：刷入 AK3 时请尽量使用「刷写 AK3」选项，只有出现问题时才考虑使用「刷入 AK3 压缩包（mkbootfs）」。此选项计划于 v3.0（30000）中开始废弃。
  5. 关于「刷入 KernelSU LKM Driver」：此功能是从上游分支 KernelFlasher 继承而来，不建议使用，因为它可能导致问题，计划将在 v2.9（20900）中废弃。
  6. 刷入分区镜像：点击进入之后可以看到预设分区 boot、dtbo、init_boot、recovery、system_dlkm、vbmeta、vendor_boot。点击想要刷入的分区，选择对应的 *.img、*.bin 文件，弹出二次确认弹窗后点击确认继续刷写。

4. 备份 & 恢复（包含重要提示）

4.1 备份 & 恢复

点击「备份」按钮进入备份页面，预设分区：boot、dtbo、init_boot、recovery、system_dlkm、vbmeta、vendor_boot、vendor_dlkm。

勾选完想要备份的分区后，点击「备份选定分区」按钮即可开始备份。备份完成后，可回到主页点击底栏「备份」选项查看备份。

注意：恢复备份须到刷写页面点击「恢复」按钮，恢复对应槽位的备份。

4.2 重要提示

我们强烈建议开启「自动备份」作为保险。AK3 支持一键回滚，可以在「操作记录」以及「备份」中触发。

5. 百宝箱内工具介绍

在「设置」页点击「百宝箱」即可进入：

5.1 解包（Payload-Dumper）

用于从 OTA 的 payload.bin 中提取 .img 分区文件。

  • 解包：点击后选择 payload.bin 文件，应用会使用内置的 payload-dumper-go 工具提取其中的 .img 分区文件。
  • 解包记录：查看已解包的 .img 文件（默认目录 /sdcard/ReKernelFlasher/img/），长按记录可使用系统文件管理器打开。

5.2 字库备份（全量备份）

用于备份除 userdata、sdc 以外的所有分区，备份记录会显示在「备份」页面。

  • 进入后自动检测平台、分区总数、跳过分区以及预计占用空间。
  • 默认备份目录：/sdcard/ReKernelFlasher/backups/型号字库备份，支持自定义目录与「重置目录」。
  • 点击「开始字库备份」后弹出确认弹窗，确认后开始备份，完成后显示成功 / 跳过 / 失败数量。

5.3 修复 RKP（实验性）

用于修复骁龙（高通）设备因解锁 BL 导致的 TEE 假死、RKP 不可用问题。

  • 仅适用于高通（Qualcomm）平台，联发科（MediaTek）勿用！
  • 两种修复方案：「Qcom 8 Elite Gen5（Beta）」与「处理器 ≤ 8 Elite」。
  • 执行前会自动备份 persist 分区，并输出完整日志。
警告：本功能是实验性的，仅供尝鲜，可能引发设备问题。如因此功能出现问题，请勿提交相关 issue。

5.4 开启高通 Diag 端口

用于开启高通设备的 Diag 调试端口，供 QPST / QXDM 等工具连接设备。

  • 内部通过 setprop sys.usb.config diag,adb 开启端口。
  • 仅供骁龙设备使用，天玑设备禁止使用！
  • 开启端口前请确保手机已经连接电脑。

5.5 开启无线调试端口

用于在指定端口开启 adbd 服务（adb over TCP），方便在电脑上通过 adb connect 无线连接调试。

  • 输入端口号（范围 1024 – 65535），端口合法时右侧「纸飞机」发送按钮才会由灰变亮。
  • 端口不合法时，下方显示红色提示：端口不合法，请输入1024-65535之间的数字。
  • 点击发送后先检查通知权限，未授权则拉起系统授权框；授权通过后执行 setprop service.adb.tcp.port {端口} && stop adbd && start adbd。
  • 若端口已开启，应用会自动识别并跳过开端口，直接显示已开启状态。
  • 开启成功后：通知栏显示常驻通知（内含「停止」按钮），输入框与发送按钮变灰，并显示「adbd服务已在{端口}上开启」。
  • 点击「停止」会执行 setprop service.adb.tcp.port 0 && stop adbd && start adbd 关闭端口并恢复原界面。

6. 应用设置

设置页主要包含：检查更新、自动备份设置、语言设置、日志设置、高级设置以及百宝箱。

6.1 保存日志（日志设置）

  • 保存 ramoops：保存内核 panic / oops 崩溃日志（仅当设备存在 ramoops 时显示）。
  • 保存 dmesg：保存内核环形缓冲区日志。
  • 保存 logcat：保存 Android 系统日志。

6.2 高级设置

  • 界面缩放（DPI）：拖动滑条调整界面缩放比例（范围 50% – 150%），点击「应用」后生效，仅对当前会话生效。

6.3 语言设置

  • 简体中文
  • 繁體中文（香港）
  • 繁體中文（台灣）
  • English

1. Information Reading & Display (Home)

After launching, the app automatically reads device information and displays it on the home screen:

The home screen reads:

  • Device ROOT Manager
  • Android Version
  • Device Codename
  • System Build Version
  • Current Slot
  • BootHAL
  • SUSFS Version
  • Kernel Version

2. Slots & Kernel Version Check

Switch to the "Flashing" tab. If your phone supports A/B partitions, two slots will be shown.

The info panel displays:

  • Active status
  • Vendor_DLKM
  • boot.img / init_boot.img information
Tip: Tapping "Check Kernel Version" re-scans and parses the current kernel version.

3. Flashing Features

On the "Flashing" page, tap "Flash" to enter the flashing page:

3.1 Flash AK3

  1. Local flash: Tap "Flash AK3", select your AnyKernel3 zip, and a confirmation dialog will pop up. Tap confirm to start.
  2. Cloud G(O)KI flash: Tap the cloud icon in the top-right corner to enter the Cloud G(O)KI repository, select the package, tap "Download", then confirm to flash.
  3. Special note: You can fully trust content downloaded from Cloud G(O)KI. We strongly recommend enabling "Auto Backup" in Settings, so you can quickly roll back if issues occur after booting.
  4. Important note: Prefer "Flash AK3". Only use "Flash AK3 Zip (mkbootfs)" if problems occur. It is planned to be deprecated from v3.0 (30000).
  5. About "Flash KernelSU LKM Driver": Inherited from upstream KernelFlasher; not recommended, planned to be deprecated in v2.9 (20900).
  6. Flash partition image: Tap a preset partition (boot, dtbo, init_boot, recovery, system_dlkm, vbmeta, vendor_boot), select a *.img / *.bin file, then confirm.

4. Backup & Restore (with Important Notes)

4.1 Backup & Restore

Tap "Backup" to enter the backup page. Preset partitions: boot, dtbo, init_boot, recovery, system_dlkm, vbmeta, vendor_boot, vendor_dlkm.

Select the partitions and tap "Backup Selected Partitions". After done, view backups from the bottom bar.

Note: To restore, go to the flashing page and tap "Restore" for the corresponding slot.

4.2 Important Notes

We strongly recommend enabling "Auto Backup". AK3 supports one-tap rollback from "Operation History" and "Backups".

5. Toolbox Tools

Go to Settings → "Toolbox":

5.1 Unpack (Payload-Dumper)

Extract .img partition files from an OTA payload.bin.

  • Unpack: select a payload.bin file; the built-in payload-dumper-go tool extracts the .img files.
  • Unpack records: view extracted .img files (default /sdcard/ReKernelFlasher/img/). Long-press to open.

5.2 Firmware Backup (Full Backup)

Back up all partitions except userdata and sdc.

  • Auto-detects platform, partition count, skipped partitions and estimated size.
  • Default directory: /sdcard/ReKernelFlasher/backups/{model}字库备份. Custom directory supported.
  • Tap "Start Firmware Backup" and confirm to begin.

5.3 Fix RKP (Experimental)

Fix TEE freeze / RKP unavailable on Snapdragon (Qualcomm) devices caused by an unlocked bootloader.

  • Qualcomm only. Do NOT use on MediaTek!
  • Two options: "Qcom 8 Elite Gen5 (Beta)" and "Processor ≤ 8 Elite".
  • Automatically backs up persist and outputs full logs.
Warning: This feature is experimental and may cause device issues. Do not file related issues.

5.4 Enable Qualcomm Diag Port

Enable the Diag debug port on Qualcomm devices for tools such as QPST / QXDM.

  • Internally runs setprop sys.usb.config diag,adb.
  • Snapdragon only. Do NOT use on Dimensity (MediaTek)!
  • Connect the phone to a computer first.

5.5 Enable Wireless Debugging Port

Enable the adbd service (adb over TCP) on a specified port for wireless debugging via adb connect.

  • Enter a port (1024 – 65535); the "paper plane" button lights up only when valid.
  • Invalid port shows a red hint: 端口不合法，请输入1024-65535之间的数字.
  • Checks notification permission first, then runs setprop service.adb.tcp.port {port} && stop adbd && start adbd.
  • If already enabled, it auto-detects and skips opening.
  • After enabled: a persistent notification (with "Stop") appears; the input and send button become greyed out.
  • Tap "Stop" to run setprop service.adb.tcp.port 0 && stop adbd && start adbd and restore the UI.

6. App Settings

The Settings page includes: Check for Updates, Auto Backup Settings, Language Settings, Log Settings, Advanced Settings and Toolbox.

6.1 Save Logs (Log Settings)

  • Save ramoops: save the kernel panic / oops log (shown only when ramoops exists).
  • Save dmesg: save the kernel ring buffer log.
  • Save logcat: save the Android system log.

6.2 Advanced Settings

  • UI Scale (DPI): drag the slider to adjust UI scale (50% – 150%); takes effect after tapping "Apply".

6.3 Language Settings

  • 简体中文 (Simplified Chinese)
  • 繁體中文（香港）(Traditional Chinese, Hong Kong)
  • 繁體中文（台灣）(Traditional Chinese, Taiwan)
  • English
